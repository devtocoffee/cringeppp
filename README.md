# Кринж-поинт

Домашний архив наших PowerPoint-вечеров: встречи, люди, выступления, награды и статистика.

## Публикация

В настройках репозитория откройте **Settings → Pages** и выберите **Deploy from a branch → main → /(root)**, затем **Save**.

После публикации:

- Входная дверь: https://devtocoffee.github.io/cringeppp/welcome.html
- Главная: https://devtocoffee.github.io/cringeppp/

В репозитории готовые статические HTML/CSS/JS и ресурсы. Установка зависимостей, сборка на сервере и база данных не нужны. `.nojekyll` отключает дополнительную обработку Jekyll.

## Обновления

Сайт собирается локально с базовым путём `/cringeppp/`. Для обновления замените готовые файлы свежей сборкой и отправьте коммит в `main`.

Изображения WebP сжаты без потерь. Музыка включается кнопкой в шапке; трек — Brought to You by a Falling Bob-Omb, 0x10, предоставлен организатором сайта.
